# SOCHIMI 2026 — Recursos de la charla

Sitio: https://gsalgadoma.github.io/sochimi-2026/

## Recursos publicados

- `index.html`: portada, afiliaciones docentes UANDES, visor de diapositivas integrado, seis lecturas guiadas de resultados, bibliografía comentada con filtro y enlaces DOI.
- `diapositivas.html`: lector web accesible de 27 diapositivas, navegable con teclado, descarga PDF y botón para generar PPTX.
- `presentacion-data.js`: fuente única de contenidos de la edición pública de 27 diapositivas.
- `descargar-pptx.js`: exporta las diapositivas textuales de la versión web a PowerPoint editable con PptxGenJS desde el navegador.
- `diapositivas-sochimi-2026.pdf`: edición pública descargable, sin fotografías clínicas identificables.

## Criterios editoriales

- Las notas de bibliografía son paráfrasis científicas de la charla y no sustituyen la consulta de los estudios originales.
- Distinguir siempre penetración de aspiración, asociación de causalidad y datos de trasplante de las extrapolaciones desde otras poblaciones.
- La **versión pública** del visor, PDF y PPTX generado no es una copia visual del archivo original. El original contiene fotografías clínicas que no se publican sin confirmación de autorización.
- El botón de PowerPoint necesita conexión de red para cargar PptxGenJS (biblioteca JavaScript pública). Si falla, mantener disponible PDF y visor web.
