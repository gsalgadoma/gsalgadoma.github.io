# Minor en Salud Pública — UANDES

Micrositio promocional responsivo para la Feria de Minors de la Universidad de los Andes.

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Despliegue en Vercel

1. Crear un repositorio en GitHub y subir esta carpeta.
2. En Vercel: **Add New → Project → Import Git Repository**.
3. Vercel detectará Next.js automáticamente.
4. Presionar **Deploy**.

## Identidad visual aplicada

- DM Sans como tipografía principal.
- Rojo corporativo `#CE0019` presente como elemento identitario.
- Paleta azul institucional `#131E29`, `#243746`, `#415364`, `#758592`.
- Ostra `#D6D1CA` como apoyo neutro.
- Uso de la flecha Uandes orientada hacia la derecha como motivo gráfico.
- Logo promocional Uandes obtenido del manual de marca adjunto para este prototipo.

## Contenido

Basado en la página oficial vigente del Minor en Salud Pública UANDES (consultada el 22-09-2026):
https://www.uandes.cl/estudiantes/minors/minor-en-salud-publica/

Incluye:
- Hero y propuesta de valor
- Determinantes de la salud
- Recorrido de las tres asignaturas
- Explorador de problemas reales
- Selector por carrera
- Restricciones oficiales
- Quiz interactivo de cuatro preguntas
- Información de contacto y enlaces al programa oficial

## Nota de producción

Antes del despliegue institucional definitivo, reemplazar el PNG del logo por el activo vectorial oficial entregado por Imagen Corporativa UANDES, manteniendo proporciones y área de seguridad.
